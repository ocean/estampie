# Official FM-1 V15 firmware (M-VAVE, Apache-2.0)

`FM-1_015.fwsc` is M-VAVE's official FM-1 firmware V15, unmodified. The installer's "Return to
official V15" installs it (`web/index_pkg.html`; `web/make_site.py` publishes it in the site's
`firmware/stock/`). It is not part of ESTAMPIE's firmware or packages.
