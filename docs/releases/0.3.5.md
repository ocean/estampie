ESTAMPIE 0.3.5: INFO shows ESTAMPIE's own version.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **MENU › INFO's FIRMWARE row** now shows ESTAMPIE's version (0.3.5) instead of Felucca's 1.6.1, and the screen reader says it too. ABOUT still credits Felucca 1.6.1, which ESTAMPIE is built on.
- **Screens in the README:** eleven of ESTAMPIE's screens in the VELLUM and TAVERN looks, taken from the firmware's own drawing code by `tools/screens.sh`. They're in `docs/screens/`.
- **How ESTAMPIE is made:** the README has an AI disclaimer, and [docs/AI.md](https://github.com/ocean/estampie/blob/main/docs/AI.md) explains what AI is and isn't used for, following Leo Kuroshita's note for Felucca.
- **A smaller build download:** the build now fetches only the three files it needs from JieLi's AC79 SDK (2.9 MB), not the whole SDK with its Windows tools.
- **On a Mac,** if a DAW still shows the FM-1 as "Felucca" after 0.3.4, remove it in Audio MIDI Setup › MIDI Studio and plug it in again: macOS remembers the old name.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.5.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.5`.

Thank you to Leo Kuroshita, Jason Persinger and everyone in the README and CREDITS.md. This is early work. Make a backup before you install.

**Full changelog:** https://github.com/ocean/estampie/compare/v0.3.4...v0.3.5
