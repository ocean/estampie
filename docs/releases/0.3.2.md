ESTAMPIE 0.3.2: a small tidy-up release for the website, with a security update to one of the build's tools.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **The licences open in your browser again:** the website has moved to GitHub Pages, which downloaded the licence instead of showing it. The licence, the licensing notes and the official V15 firmware's notes are now plain `.txt` pages.
- **A safer build:** the pictures on the FM-1's screen are drawn while building with Pillow, which is now 13.0.0, fixing nine advisories against 12.3.0 (one critical). Pillow only runs during the build and was never part of the firmware, so earlier releases are unaffected.
- **A pixel tidier:** with the new Pillow, a couple of the on-screen button labels (OCT- and OCT+) sit a pixel differently. Nothing else on the device changes.
- **Built from source, and signed,** like 0.3.1: GitHub built this release from the tagged commit through the [FM-1 Firmware Hub](https://thefirmwarehub.com)'s shared workflow and signed every file. Check one with `gh attestation verify estampie-0.3.2.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it yourself and compare with `tools/verify_release.sh 0.3.2`.
