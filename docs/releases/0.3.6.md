ESTAMPIE 0.3.6: the page key is SEL, as printed on the FM-1.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **SEL, not SCL:** the FM-1's panel prints **SEL** on the key that opens the scale page, but Felucca called it SCL. Now the on-screen HELP, the SEL layer's header, the first-tap hint ("HOLD SEL QUICK") and the panel test all say SEL, and so do the user guide, its panel diagram and the browser emulator's panel. The page itself is still called **SCL** on the screen, and so is its KNOB 2, the scale.
- **The screen reader** calls it the "scale button", since "SEL" alone already means MIDI's selected track.
- **Your projects and other firmwares:** the README now says what happens to saved projects when you change firmware. ESTAMPIE opens Felucca's and GHOULBOX's projects. Felucca can't open ESTAMPIE's: it shows them as EMPTY, but leaves them in the flash. Back them up with the web editor first.
- **On the FM-1 Firmware Hub:** ESTAMPIE's card text and its emulator and editor links are in `fmhub.json`.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.6.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.6`.

Thank you to Leo Kuroshita, Jason Persinger and everyone in the README and CREDITS.md. This is early work. Make a backup before you install.
