ESTAMPIE 0.3.8: works on newer FM-1s, and shows up on USB as the FM-1 does.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **Newer FM-1s:** FM-1s sold since autumn 2026 have a different flash chip (UCUN's UC25HQ80). Earlier ESTAMPIEs didn't know it, so on those units nothing was saved past power-off and ESTAMPIE couldn't be updated over USB. 0.3.8 knows both chips, as Felucca does since Leo Kuroshita's fix (Felucca#320). Tested on an FM-1 with the older chip; we'd love a report from someone with a newer one. If a newer FM-1 already has an earlier ESTAMPIE, it can't install this itself: the README's "Newer FM-1s" section says more, and please open an issue.
- **Which chip:** installers can now ask ESTAMPIE which flash chip an FM-1 has (the full identity query, as Felucca and PERF-1 answer it). The plain identity answer is unchanged, so M-UPGRADE and older installers see what they always did.
- **One "FM-1" on your computer:** ESTAMPIE now shows up on USB just as M-VAVE's V15 does, named "FM-1", so a computer keeps the one FM-1 it already knows whichever firmware runs, rather than adding another device. Record from the audio input "FM-1" (it was "FM-1 ESTAMPIE"). The update loader keeps its own name, "FM-1 ESTAMPIE Update".
- **The editor** names the ESTAMPIE release it's talking to, not just Felucca's version, and its step tables wrap on narrow windows instead of overlapping.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.8.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.8`.

Thank you to Leo Kuroshita for the newer chip's fix in Felucca, the FM-1 Firmware Hub for spreading the word, and Jason Persinger and everyone in the README and CREDITS.md. This is early work. Make a backup before you install.
