ESTAMPIE 0.3.1: the first release built and signed by GitHub, so you can check that it came from this source.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **Built from source, and signed:** this release wasn't built on anyone's computer.
  - GitHub built it from the tagged commit, using the [FM-1 Firmware Hub](https://thefirmwarehub.com)'s shared workflow ([zvenson/fm1-build](https://github.com/zvenson/fm1-build)), and ran the tests first.
  - GitHub then signed a build attestation for every file: the firmware, the app and the website.
  - The hub shows ESTAMPIE as **Built from source**, linking the exact commit and the public build log.
- **Check it yourself:** `gh attestation verify estampie-0.3.1.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`. A signature tells you where a file came from, not that it's safe; the source is all here to read.
- **Reproducible:** building the same tag on your own computer (`tools/release.sh 0.3.1`) gives the same files, byte for byte, and `tools/verify_release.sh 0.3.1` compares them. The website zip is now reproducible too.
- **Everything from 0.3.0:** the screen reader for the FM-1 and the browser version, ESTAMPIE's own words for it, and the new preview picture. The firmware itself is unchanged apart from its version number.
