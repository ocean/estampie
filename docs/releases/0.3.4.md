ESTAMPIE 0.3.4: the FM-1 now introduces itself as ESTAMPIE.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **Its own name on USB:** a computer now sees the FM-1 as **FM-1 ESTAMPIE**, for both its MIDI port and its audio input, instead of "Felucca". While updating, it shows as "FM-1 ESTAMPIE Update". So the [FM-1 Firmware Hub](https://thefirmwarehub.com), installers and music software can tell what's installed.
- **If you record or play the FM-1 in a DAW**, choose "FM-1 ESTAMPIE" as the MIDI port or audio input once after updating. On a Mac, if it still shows the old name, remove the FM-1 in Audio MIDI Setup and plug it in again.
- **The editor and the tools** find the FM-1 under either name, so older ESTAMPIE versions still work with them.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.4.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.4`.

Thank you to the FM-1 Firmware Hub for its guidance on identities, and to everyone in the README and CREDITS.md. This is early work. Make a backup before you install.
