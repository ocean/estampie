ESTAMPIE 0.3.7: installs with m-bootloader both ways, and helps you out of the Felucca loop.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **m-bootloader friendly:** ESTAMPIE's USB update now takes any well-made package, after Charles Vestal's fix to Felucca's platform (felucca-bsp `afd83ed`, MPL-2.0). On an FM-1 with Julius Vitkauskas's [m-bootloader](https://github.com/jvitkauskas/m-bootloader), ESTAMPIE installs over it and keeps it, and from ESTAMPIE you can install official V15 (which brings M-VAVE's own bootloader back), M-VAVE's Open V12 and V14, or m-bootloader's own installer. Tested on an FM-1: ESTAMPIE over m-bootloader, V15 from ESTAMPIE, and m-bootloader back on (Open V12 and V14 not yet tried).
- **Out of the Felucca loop:** with m-bootloader installed, firmwares on Felucca's older update code (Felucca, GHOULBOX and ESTAMPIE before 0.3.7, among others) install each other but refuse official V15. Install ESTAMPIE 0.3.7, then return to V15 or install anything else from there. The user guide's new "With m-bootloader" section explains it, and that the recovery menu's wipe erases your projects and samples.
- **For developers:** `./build.sh` now writes `build/estampie.fwsc` (and `.bin`, `.elf`), not `felucca.*`.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.7.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.7`.

Thank you to Charles Vestal for the update fix, Julius Vitkauskas for m-bootloader, and Leo Kuroshita, Jason Persinger and everyone in the README and CREDITS.md. This is early work. Make a backup before you install.
