ESTAMPIE 0.3.3: a few small updates to the website. The firmware is unchanged apart from its version number.

**Install it** from the browser at https://fm-1.drewr.dev/estampie/webapp/installer/ (Chrome or Edge), or install the `.fwsc` with FM1Kit or FM-SWITCH. **Try it first** in your browser at https://fm-1.drewr.dev/estampie/webapp/emu/.

### What's new

- **Minor website updates:** the front page now has a link to support ESTAMPIE on [Ko-fi](https://ko-fi.com/oceanicity), if you'd like to.
- **Built from source, and signed,** like every release since 0.3.1: check a file with `gh attestation verify estampie-0.3.3.fwsc --repo ocean/estampie --signer-workflow zvenson/fm1-build/.github/workflows/build.yml`, or rebuild it and compare with `tools/verify_release.sh 0.3.3`.

Thank you to everyone in the README and CREDITS.md. This is early work. Make a backup before you install.

**Full changelog:** https://github.com/ocean/estampie/compare/v0.3.2...v0.3.3
